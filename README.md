# UtilClic

Herramientas gratis para estudiantes, en español. Todo se procesa en tu navegador: tus archivos nunca se suben a un servidor.

**Sitio:** https://yamilyt-boop.github.io/Utilclic/

## Herramientas

- **Formato APA 7:** sube tu Word y descárgalo con el formato APA aplicado (portada, márgenes, interlineado, títulos, figuras, tablas y referencias). Antes revisa que tus citas coincidan con tus referencias.
- **Generador de citas APA:** referencias y citas para libros, artículos, páginas web, periódicos, leyes, informes, redes sociales, software, IA y más.
- **Mayúsculas para títulos:** tipo oración o tipo título.
- **Lista de verificación APA:** repasa tu trabajo antes de entregarlo.
- **Unir PDF, dividir PDF e imágenes a PDF.**
- **Contador de palabras.**
